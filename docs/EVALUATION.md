## Limitations of This Evaluation

- The data is small (45 items), fictional and annotated by the project author, so results indicate behaviour rather than clinical accuracy.
- Warning-sign matching uses phrase overlap, which can be lenient for partial matches.
- Fault injection tests the verifier against synthetic errors. Real model errors can be subtler.
- Per-prohibition coverage is checked for English output only. Hindi and Marathi rely on the v1 negation check plus dose binding.
- No patient comprehension study was performed.
